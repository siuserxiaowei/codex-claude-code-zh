# 401 / 403：鉴权与权限

[← 返回目录](../README.md)

**401 = 服务器不认你的身份；403 = 认出你了，但不允许这个操作。** 两者都不是“额度不够”，先别花钱。

## 401

| 报错关键词 | 含义 | 处理 |
| --- | --- | --- |
| Missing bearer / 未带认证 | 本地没有可用会话或 Key | 重新 `codex login`，或确认环境变量真的被当前进程读到 |
| Incorrect API key / `invalid_api_key` | Key 不对：复制缺位、已撤销、或把中转 Key 当官方 Key | 到对应控制台核对 Key 所属项目，必要时轮换 |
| Invalid Authentication | 登录态失效或登录的不是预期账号 | `codex logout` 后重新登录 |
| IP not authorized | API 项目配置了 IP 白名单 | 找管理员核对允许列表 |

建议顺序：

```bash
codex --version
codex login status
```

1. 复制完整报错一行（中间字符可以打码）。
2. ChatGPT 登录路径：重新走浏览器授权；无桌面的远程环境先确认官方支持的登录方式。
3. API Key 路径：控制台确认 Key 有效、项目正确；用了自定义 provider，**Base URL 和 Key 要同时核对**。
4. 还不行：升级到最新版本再试，排除旧版本 bug。

## 403

| 报错关键词 | 含义 | 处理 |
| --- | --- | --- |
| Country, region, or territory not supported | 地区不在支持清单 | 这是资格问题，升级套餐或买卡密都解决不了 |
| permission denied / 工作区限制 | 组织、项目角色或管理员策略不允许 | 找工作区管理员；不要关沙箱或改组织策略硬闯 |

## Claude Code 的 401 / 403

接入第三方兼容端点时，最常见的原因是 **Base URL、Key、产品、地域不是同一套**（例如百炼按量 Key 配了 Coding Plan 端点）。见 [Claude Code 安装与接入](claude-code-install.md)。

## 不要做的事

- 把 `auth.json`、完整环境变量、登录二维码贴进群或工单。
- 一遇到 401 就删掉整个配置目录或去买新账号。

对照表原文见 [Codex 401 / 429 / 超时 30 秒分流](https://nano-banana.lol/how-to/codex-401-429-timeout-triage)。
